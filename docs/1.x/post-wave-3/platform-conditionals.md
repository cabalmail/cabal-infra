## Why

- **The code is hard to read and cannot be tested across platforms.** 141 platform `#if` blocks sit in 55 shared files outside `Shell/` and `Platform/`. Code compiled for one OS cannot be unit-tested from the Mac test host; a `HostPlatform`-keyed policy can be, for all four platforms (the `ConfirmationDialogPolicy` pattern). The 2026-10-02 audit called the spread a "readability and correctness risk for a non-Swift-fluent owner".
- **The maintainer asked for this follow-up,** answering the 3.2 scope question (how far 3.2 takes "`#if` only in shells and adapters"): "Ratchet, but let's document the rest for follow-up work." (the maintainer, 2026-10-09). 3.2 G added the ratchet; the rest is catalogued block by block as FU-1 to FU-19 in `../platform-conditionals-followups.md` (the catalogue). None has started.
- **Two soak bugs live in Rules, which this plan owns as a hotspot.** #2031 (Add rule saves an enabled, empty rule and does not open its editor) and #2040 (the Mac rule switch reads as "toggle button" to VoiceOver), both open, both filed from the Wave 3 soak. #2040's fix is a Mac-only accessibility difference, which by the ratchet's rule belongs in a `Platform/` adapter.
- **Other plans wait on pieces of it.** FU-1 (shared-load-error-state.md B3, duo-support.md Session 3), FU-9 (feed-bulk-actions.md PR E), the Rules fixes (flags-and-cross-media.md G3).
