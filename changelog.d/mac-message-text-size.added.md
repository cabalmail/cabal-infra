- Apple: **Message text size on the Mac.** macOS has no Dynamic Type, so
  Settings > Appearance now has a Message text setting, from Extra Small to
  Extra Large, with Medium the size from before. It scales message bodies
  (HTML and plain text), feed articles in reader styling, and the
  composer. View > Larger Message Text (⌘+), Smaller Message Text (⌘−)
  and Default Message Text Size (⌘0) change it from any window. The size
  is kept on the device rather than synced with the account
  (`AppTextSize`, `contentTextScale`).
