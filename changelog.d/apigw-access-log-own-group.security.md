- **The API Gateway access log has a log group of its own.** The stage's access log was written into the execution log group — the one whose per-method overrides had been running at `INFO` with request/response tracing on, so it holds truncated request bodies and `Authorization` headers alongside the per-request access records. One group meant one retention for both, and the only lever for ageing the body history out would have taken the access log with it. The two are now separate groups, each with its own retention; entries already written stay in the group that received them.
